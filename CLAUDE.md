## Project Overview

This is a **Next.js static website** for iCube, a GameCube/Wii emulator for iOS/tvOS. It serves as a marketing site and IPA distribution platform compatible with AltStore/SideStore.

**Production domain: `https://icube-emu.com`** — this is the canonical domain for all absolute URLs, metadata, Open Graph, AltStore/SideStore feeds, and CI workflows. Never use `icube-app.com` — that domain does not exist.

## Commands

```bash
npm run dev          # Start dev server (Turbopack)
npm run build        # Production build (runs prebuild first)
npm run lint         # Run ESLint
npm run lint:fix     # Fix ESLint issues
npm run type-check   # TypeScript type checking
npm run clean        # Remove .next, .turbo, cache
```

The `prebuild` script (`scripts/generate-versioned-ipas.js`) runs automatically before `npm run build` — it modifies IPA files in `public/builds/` with unique version numbers and outputs them to `public/builds-versioned/`.

## Architecture

### Core Concepts

**Static Export:** `next.config.ts` sets `output: 'export'` and `trailingSlash: true`. Image optimization is disabled. All API routes must use static generation.

**Build Distribution System:**
- `public/builds/` — Original IPA files organized as `{version}/{platform}/` (e.g., `1.0.0/iOS-Beta9/`)
- `public/builds-versioned/` — Generated by prebuild script; IPAs with modified version numbers for static hosting
- `src/lib/buildParser.ts` — Core logic: parses build directory structure, reads `DistributionSummary.plist` files, returns sorted `BuildVersion[]`, and generates AltStore-compatible app metadata

**AltStore/SideStore Feed:**
- `src/app/api/altstore/route.ts` and `src/app/api/sidestore/route.ts` — Static-generated JSON feed endpoints
- Uses `generateAltStoreApp()` from `buildParser.ts` to produce the feed
- iOS-only filter applied to avoid duplicate version errors in AltStore
- `NEXT_PUBLIC_BASE_URL` env var required for absolute URLs in the feed

### Build Directory Convention

```
public/builds/{semver}/{platform}/
  iCube.ipa
  DistributionSummary.plist
  ExportOptions.plist
```

Platform names: `iOS`, `tvOS`, `iOS-BetaN`, `tvOS-BetaN` (where N is the beta number).

### Path Alias

`@/*` maps to `./src/*` (configured in `tsconfig.json`).

### Deployment

GitHub Actions (`.github/workflows/deploy.yml`) builds and deploys to GitHub Pages on push to `main`. The workflow runs the versioned IPA script, builds, then deploys via `actions/deploy-pages`.
